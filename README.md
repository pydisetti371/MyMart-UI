# React Starter

A Vite powered React and TypeScript starter with Tailwind CSS, React Router,
ESLint, and Prettier.

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` type checks and builds the production app.
- `npm run lint` checks the source with ESLint.
- `npm run format` formats the project with Prettier.
- `npm run format:check` checks formatting without changing files.

The starter includes Home and About routes. Add pages in `src/App.tsx` or split
them into route modules as the app grows.
